# School branding

The school mark combines an open book with a school roof in the existing primary blue (#2F4FD8). The shared SchoolLogo component is used by school navigation, account entry, public pages and role workspaces. The configured school name and uploaded school logo remain supported.

Assets: public/brand/school-mark.svg, src/app/icon.svg, src/app/favicon.ico (32/48/256px) and src/app/apple-icon.png (180px).

Product wording uses school, workspace, enquiry and connection status. Account hints and prefilled passwords are removed. Private test-account safeguards remain enabled only by explicit server configuration. Established storage keys, account IDs and record references are retained for compatibility; branding must never reset a workspace or invalidate relationships.

Account addresses and historical record identifiers remain unchanged. Any change to an existing sign-in address requires separate authorization; wording cleanup does not imply a credential migration.
